# Todo List V1

A simple and useful Todo List for different users.

## About

This project was made with Python 3.14.6.

It is a simple command-line Todo List that helps users add, view, and remove tasks.

## Features

- Add new tasks
- View tasks
- Remove tasks
- Simple menu system
- Tested and improved for a better user experience

## How to Use

It is very simple:

1. Run the Python file.
2. Add your tasks.
3. View your tasks.
4. Remove tasks you don't need anymore.
